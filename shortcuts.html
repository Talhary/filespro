FilesPro keyboard shortcuts

Every action in FilesPro is a command, and every command can have a shortcut. These are the defaults.

Can't remember one? Press CtrlShiftP to open the command palette, type a few letters of what you want, and press Enter. The palette shows each command's shortcut next to it.

Change any shortcut

Open the key editor with CtrlK. Start from the File Explorer, Total Commander or Vim preset, change any shortcut, and export your keymap to take it to another PC. The Total Commander preset changes some keys to match that app; the list below shows the default preset.

Optional Vim keys in file lists add j/k/h/l, gg/G and /. Turn them on from the command palette: Vim keys in file lists.

You can also just start typing in a file list to jump to the first file whose name starts with those letters.
