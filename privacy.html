Privacy Policy

Effective date: 18 October 2026

FilesPro does not collect, sell or share any personal data. It has no account, no ads, no analytics and no telemetry, and it makes no network connections of its own.

What stays on your PC

To work as a file manager, FilesPro reads the files and folders on your own PC. It stores your settings, tabs, favorites, history, undo journal, a search index of file and folder names (no contents) and crash logs locally in %LOCALAPPDATA%\FilesPro. In the Microsoft Store edition this data is removed when you uninstall the app. Nothing is uploaded anywhere.

Optional index service

If you turn on instant search on all drives (an administrator prompt asks first), a local Windows service reads file and folder names from your drives and keeps them in memory only. It sends nothing anywhere and can be removed at any time.

Crash reports

Crash reports are never sent automatically. After a crash, FilesPro asks whether you want to report it. Only if you choose to, it opens a pre-filled email in your own mail app, which you can read and edit before sending. It may contain file paths from the crash log. Reports are used only to fix problems and are deleted when no longer needed.

Third parties

FilesPro has no third-party advertising, analytics or crash reporting SDKs. It uses components of Windows itself, governed by the Microsoft Privacy Statement. Microsoft may give the developer aggregated, de-identified Store statistics such as install counts and ratings.

Your control

You can clear the search index and logs in Settings, or delete everything by uninstalling FilesPro.

Children

FilesPro does not knowingly collect information from anyone, including children under 13.

Changes

If FilesPro ever starts to send any data, this policy will be updated before that version is released.

This website

This website has no cookies, analytics or trackers. It is hosted on GitHub Pages, which may log visitors' IP addresses for security; see the GitHub Privacy Statement.
